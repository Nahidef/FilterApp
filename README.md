#FilterApp

Bu Windows Forms uygulaması ile resimlere temel görüntü işleme filtreleri uygulanabilir.

## Özellikler
- Gri tonlama (Grayscale)
- Gauss filtresi (Gaussian Blur)
- Kenar tespiti (Sobel Edge Detection)

## Kullanım
1. Bir resim dosyası seçin.
2. Uygulanacak filtreyi ComboBox’tan seçin.
3. `Filtre Uygula` butonuna basarak sonucu görüntüleyin.

## Gereksinimler
- .NET Framework 4.7.2 veya üstü
